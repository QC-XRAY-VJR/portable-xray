# Portable X-ray · ระบบติดตามเครื่องเอกซเรย์เคลื่อนที่ (แอป PWA บน GitHub Pages)

หน้านี้คือ "แอป" ของระบบ Portable X-ray สำหรับติดตั้งบนมือถือ แท็บเล็ต และคอมพิวเตอร์ — ตัวระบบจริงยังทำงานบน Google Apps Script เหมือนเดิม
หน้านี้แค่เปิดระบบไว้เต็มจอ พร้อมไอคอน ชื่อแอป และหน้ารอโหลด

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าแอป (เปิดระบบ Apps Script เต็มจอ + ปุ่มติดตั้ง + คำแนะนำ iPhone) |
| `config.js` | **ใส่ลิงก์ระบบ** (Web app URL ที่ลงท้าย `/exec`) — แก้ไฟล์นี้ไฟล์เดียว |
| `manifest.webmanifest` | ชื่อแอป สี และรายการไอคอน |
| `sw.js` | service worker (ทำให้ติดตั้งเป็นแอปได้) |
| `favicon.ico`, `favicon.svg` | ไอคอนแท็บเบราว์เซอร์ (16/32/48 px) |
| `apple-touch-icon.png` | ไอคอนบน iPhone/iPad |
| `icons/` | ไอคอนทุกขนาด 16–512 px + maskable (Android) |
| `logo/` | โลโก้เต็ม พื้นสว่าง/พื้นเข้ม (PNG + SVG แก้ไขได้) |
| `app-icon.svg`, `maskable-icon.svg` | ต้นฉบับไอคอน (แก้สี/รูปได้ใน Figma, Illustrator, Inkscape) |

## ติดตั้งครั้งแรก

1. **สร้าง repository ใหม่บน GitHub** (เช่น `portable-xray`) ตั้งเป็น Public
2. **อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้** (Add file › Upload files ลากทั้งโฟลเดอร์ให้โครงสร้าง `icons/` และ `logo/` อยู่ครบ) แล้ว Commit
3. **แก้ `config.js`**: กดไฟล์ › รูปดินสอ › เปลี่ยน `appUrl` เป็นลิงก์ Web app ของระบบ (Apps Script › Deploy › Manage deployments › คัดลอก Web app URL ที่ลงท้าย `/exec`) › Commit
4. **เปิด GitHub Pages**: Settings › Pages › Source: *Deploy from a branch* › Branch: `main` / `(root)` › Save
   รอ 1–2 นาที จะได้ลิงก์แบบ `https://<ชื่อผู้ใช้>.github.io/portable-xray/`
5. **แก้ `Code.gs` ในระบบ** (มีให้แล้วในไฟล์ Code.gs ชุดล่าสุด บรรทัดบนฟังก์ชัน `doGet`):
   ```js
   const APP_ICON_URL = 'https://<ชื่อผู้ใช้>.github.io/portable-xray/icons/icon-192x192.png'; // ไอคอนแท็บเบราว์เซอร์
   const ALLOW_EMBED = true; // ต้องเป็น true เพื่อให้หน้าแอปเปิดระบบไว้ข้างในได้
   ```
   บันทึก แล้ว **Deploy › Manage deployments › รูปดินสอ › New version › Deploy** (ลิงก์ `/exec` เดิมใช้ต่อได้)
6. เปิดลิงก์ GitHub Pages ทดสอบ — ต้องเห็นหน้ารอโหลดพร้อมโลโก้ แล้วตามด้วยหน้าเข้าสู่ระบบ

## ติดตั้งเป็นแอป

- **คอมพิวเตอร์ (Chrome / Edge):** ปุ่ม "ติดตั้งแอป Portable X-ray" มุมขวาล่าง หรือไอคอนติดตั้งในแถบที่อยู่
- **Android (Chrome):** ปุ่มติดตั้งมุมขวาล่าง หรือเมนู ⋮ › ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก
- **iPhone / iPad (Safari):** ปุ่มแชร์ › เพิ่มไปยังหน้าจอโฮม (หน้าแอปมีคำแนะนำขึ้นให้ครั้งแรก)
- **จอวอร์ด:** เปิดลิงก์ `.../portable-xray/?view=ward` แล้วติดตั้ง — พารามิเตอร์ต่อท้ายจะถูกส่งต่อให้ระบบ

## อัปเดตภายหลัง

- **เปลี่ยนโค้ดระบบ:** แก้ใน Apps Script แล้ว Deploy New version ตามปกติ — ไม่ต้องแตะ GitHub
- **เปลี่ยนไอคอน/โลโก้:** อัปโหลดไฟล์ใหม่ทับ แล้วแก้ `sw.js` บรรทัด `CACHE_NAME` เพิ่มเลขเวอร์ชัน (เช่น `pxr-shell-v2`) เพื่อให้เครื่องผู้ใช้โหลดของใหม่
- **เปลี่ยนลิงก์ระบบ:** แก้ `config.js` อย่างเดียว

## หมายเหตุ

- `ALLOW_EMBED = true` อนุญาตให้เว็บอื่นฝังหน้าระบบได้ (จำเป็นสำหรับแอป) — ทุกการใช้งานยังต้องเข้าสู่ระบบเหมือนเดิม ถ้าไม่ใช้แอปแล้วตั้งเป็น `false` ได้
- ถ้าเบราว์เซอร์บล็อกการเปิดระบบข้างในหน้าแอป (เช่น ตั้งค่าบล็อกคุกกี้บุคคลที่สามเข้มงวด) หน้าแอปจะแสดงปุ่ม "เปิดระบบในแท็บใหม่" ให้เอง
- ระบบต้อง Deploy แบบ *Who has access: Anyone* (เหมือนเดิม) จึงจะเปิดในหน้าแอปได้
